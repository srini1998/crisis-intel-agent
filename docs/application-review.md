# Application review / October 18, 2026 UTC

The original deterministic verifier checks citation IDs, numeric overlap and selected structured fields. It does not establish semantic entailment or factual truth. An authored nonnumeric unsupported claim passes those limited checks; this is now tested as a documented boundary. The API adds explicit factual-status/scope metadata and the dashboard labels generated claims and structural checks. Historical evaluation files retain their original field names and are not retroactively rewritten as stronger evidence.

Boolean citation IDs are rejected. SQLite uses a separate connection per FastAPI request-pool thread, avoiding a reproduced class of cross-thread connection failures; an actual synchronized two-thread read checks that behavior. No remote feed mutation or paid API was used. The independent project suite now has 12 passing checks (previously nine).

The prompt-injection measurements describe the recorded local model, snapshot and attack set. They do not prove a universal property of system prompts, sanitizers or incident reporting. Treat this as a local inspection tool, not an official warning or autonomous response system.
