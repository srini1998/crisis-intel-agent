# Travel report interface

The public site now presents destination search across official feed titles and immediate deterministic source briefs. It is English-only and does not instantiate the former browser LLM worker. Agency reports remain direct browser requests; unavailable feeds and empty matches remain visible. This is not a destination safety or travel advisory service.

The Python agent, previous browser worker source and historical model experiments remain in the repository for reproducibility; none establishes that a current source brief was generated by AI. Citation/number checks do not prove semantic truth. Copying a brief records its actual structured inputs/output in the technical side panel.

Validation: TypeScript/build; six citation-scope checks; actual Chrome official feed retrieval (60 visible records), place search, honest empty state, English-only, desktop/390px and zero model requests. Report in parent delivery/evidence/fieldbrief-travel-browser.json.

## Optional checked AI brief (Oct 22, 2026)
Below the deterministic source brief, "Write a checked AI brief" sends the selected incident's sanitized agency reports (instruction-like sentences removed by `sanitize`) to openai/gpt-oss-20b on Groq's free plan through server-side api/generate.js (key never in browser code; ≤320 output tokens; per-IP 12/min and 60/day, 300/day per instance; Groq free account quota is the hard backstop; 429 has no paid fallback; 503 before any provider call when GROQ_API_KEY + GROQ_FREE_PLAN_CONFIRMED=true are not set). The reply is parsed with `parseModelReport` and checked with the existing `verify`: each FACT must cite an existing report, every number must appear in the cited report, and the alert level must equal the publishers' highest level. Failing sentences are struck through with the reason; model and latency are shown; the run is recorded in the trace panel. Factual truth is not established. The deterministic source brief remains the default and needs no AI.
