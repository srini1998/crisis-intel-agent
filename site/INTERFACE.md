# Travel report interface

The public site now presents destination search across official feed titles and immediate deterministic source briefs. It is English-only and does not instantiate the former browser LLM worker. Agency reports remain direct browser requests; unavailable feeds and empty matches remain visible. This is not a destination safety or travel advisory service.

The Python agent, previous browser worker source and historical model experiments remain in the repository for reproducibility; none establishes that a current source brief was generated by AI. Citation/number checks do not prove semantic truth. Copying a brief records its actual structured inputs/output in the technical side panel.

Validation: TypeScript/build; six citation-scope checks; actual Chrome official feed retrieval (60 visible records), place search, honest empty state, English-only, desktop/390px and zero model requests. Report in parent delivery/evidence/fieldbrief-travel-browser.json.
